# Retos de Lógica de Programación Básicos en Python

Este repositorio contiene una serie de retos de programación en Python diseñados para ayudarte a mejorar tu lógica de programación de manera gradual. Estos ejercicios son ideales para principiantes y aquellos que buscan fortalecer sus habilidades fundamentales en la resolución de problemas a través del código.

## ¿Qué son los Retos de Lógica de Programación?

Los retos de lógica de programación son problemas sencillos que requieren aplicar los conceptos básicos de la programación, como variables, tipos de datos, estructuras de control (condicionales y bucles) y operadores, para llegar a una solución. El objetivo principal no es la complejidad algorítmica, sino el desarrollo del pensamiento lógico y la capacidad de traducir un problema en una secuencia de instrucciones que una computadora pueda ejecutar.

Al resolver estos retos, podrás:

* **Afianzar los fundamentos de Python:** Practicar la sintaxis y el uso de las estructuras básicas del lenguaje.
* **Desarrollar el pensamiento lógico:** Aprender a descomponer problemas en pasos más pequeños y a encontrar soluciones secuenciales.
* **Mejorar la resolución de problemas:** Adquirir la habilidad de analizar un problema y diseñar una estrategia para resolverlo mediante código.
* **Ganar confianza:** Ver cómo tus conocimientos se aplican en la práctica y construir una base sólida para aprender conceptos más avanzados.

## Retos Incluidos

Actualmente, este repositorio incluye los siguientes retos básicos:

1.  **Detector de Palíndromos:** Escribe un programa que determine si una cadena de texto es un palíndromo.
2.  **Calculadora Simple:** Crea una calculadora que realice operaciones aritméticas básicas.
3.  **Adivina el Número:** Implementa un juego donde el usuario intenta adivinar un número aleatorio.
4.  **Tabla de Multiplicar:** Genera la tabla de multiplicar de un número ingresado por el usuario.
5.  **Suma de Dígitos:** Calcula la suma de los dígitos de un número entero.
6.  **Encontrando el Mayor:** Determina el mayor de tres números ingresados por el usuario.

Puedes encontrar las soluciones a estos retos (con explicaciones detalladas) en este mismo repositorio.

## ¡Contribuye con tus Propios Retos!

Este es un proyecto abierto a la comunidad. Si has resuelto estos retos y quieres compartir tus propios ejercicios básicos para ayudar a otros a mejorar su lógica de programación, ¡te invitamos a contribuir!

**¿Cómo puedes contribuir?**

1.  **Crea tu propio reto:** Piensa en un problema básico de programación que se pueda resolver utilizando los conceptos fundamentales de Python.
2.  **Escribe el código de la solución:** Implementa una solución clara y funcional en Python para tu reto.
3.  **Incluye una explicación:** Añade comentarios detallados en tu código explicando cada paso y la lógica utilizada.
4.  **Crea un archivo Markdown (.md):** Describe tu reto en un archivo `.md`. Incluye:
    * El enunciado del problema.
    * Ejemplos de entrada y salida (si aplica).
    * Cualquier pista o sugerencia que pueda ser útil para quien intente resolverlo.
5.  **Realiza un Pull Request:** Sigue los pasos detallados a continuación para enviar tu contribución.

### Pasos para Realizar un Pull Request

1.  **Haz un Fork del Repositorio:**
    * Ve al repositorio original en GitHub.
    * Haz clic en el botón "Fork" en la esquina superior derecha.
    * Selecciona tu cuenta de GitHub para crear una copia del repositorio en tu cuenta.

2.  **Clona tu Fork a tu Computadora Local:**
    * Ve a tu fork del repositorio en GitHub.
    * Haz clic en el botón "Code" y copia la URL del repositorio (asegúrate de estar en HTTPS o SSH según tu configuración).
    * Abre tu terminal o línea de comandos y navega a la carpeta donde quieras guardar el proyecto.
    * Ejecuta: `git clone URL_DE_TU_FORK` (reemplaza `URL_DE_TU_FORK` con la URL que copiaste).

3.  **Crea una Nueva Rama para tu Contribución:**
    * Navega a la carpeta del repositorio clonado: `cd nombre-del-repositorio`.
    * Crea una nueva rama con un nombre descriptivo: `git checkout -b nombre-de-tu-rama` (ejemplo: `git checkout -b agregar-reto-ordenamiento`).

4.  **Agrega tu Reto y su Explicación:**
    * Dentro de la carpeta de tu repositorio local, crea los archivos necesarios: un archivo Python con la solución (`reto_nombre.py`) y un archivo Markdown con la descripción del reto (`reto_nombre.md`).
    * Guarda estos archivos dentro de la estructura del repositorio.

5.  **Commitea tus Cambios:**
    * Añade tus archivos al área de staging: `git add reto_nombre.py reto_nombre.md`.
    * Commitea tus cambios con un mensaje claro: `git commit -m "Agrega nuevo reto: Nombre del reto"`.

6.  **Sube tu Rama a tu Fork en GitHub:**
    * Ejecuta: `git push origin nombre-de-tu-rama`.

7.  **Crea el Pull Request:**
    * Ve a tu fork del repositorio en GitHub.
    * Verás un aviso para comparar y crear un Pull Request. Haz clic en él.
    * Asegúrate de que la "base repository" sea el repositorio original y la "compare branch" sea tu rama.
    * Revisa los cambios y añade un título y una descripción clara para tu Pull Request.
    * Haz clic en "Create pull request".

8.  **Espera la Revisión:** Los mantenedores del repositorio revisarán tu Pull Request y te darán feedback si es necesario.

9.  **¡Tu Contribución (Potencialmente) se Fusiona!** Si tu Pull Request es aprobado, se fusionará con la rama principal del repositorio.
